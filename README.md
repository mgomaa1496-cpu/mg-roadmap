# خارطة محمد جمعة المهنية

صفحة عربية متجاوبة وتطبيق ويب تقدمي (PWA) لعرض خارطة التطور المهني من تطوير عمليات المصنع إلى بناء كيان تقني صناعي مستقل.

## محتوى الخطة

1. الهوية المهنية: LinkedIn ثم CV ثم Portfolio.
2. توثيق مشاريع المصنع كدليل خبرة، ومنها تكامل Excitech EP380 والتحول الرقمي.
3. بناء براند تجاري ومحتوى متخصص بالتوازي، مع تفضيل الظهور من خلف الكواليس.
4. تنمية الجمهور والشبكة المهنية.
5. اختبار خدمات عملية وبناء دخل تدريجي.
6. تطوير منتج برمجي للمصانع والتحقق منه مع المستخدمين.
7. بناء كيان مستقل والتوسع بعد استقرار الدخل، مع الحفاظ على الوظيفة خلال التأسيس.

المراحل تعرض اتجاهًا وخطوات عمل، ولا تستخدم نسب إنجاز غير موثقة. منصة المصنع الموحدة هدف تطويري وليست ERP مكتملًا.

## التشغيل والنشر

الملفات ثابتة ولا تتطلب بناءً أو اعتماديات. انشر محتويات المستودع على GitHub Pages من الفرع main. يتطلب تثبيت PWA اتصال HTTPS، وتحدّث ذاكرة الخدمة تلقائيًا عند تغيير إصدارها في sw.js.
